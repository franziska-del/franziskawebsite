# Site Plan

## Brief
Create a deployment-ready, high-fidelity static clone of `https://franziskaiseli.com` for the client, preserving the current public site’s pages, content, imagery, typography, responsive behavior, and navigation while making the result suitable for Cloudflare Pages.

## Assumptions
- The client controls or has permission to reuse the source site’s content and assets.
- Public pages and public media are in scope; WordPress administration, authoring, and database functionality are not.
- External destinations such as social profiles, Amazon, YouTube, and Basic Bananas should remain external.
- WordPress-only back-end endpoints may remain pointed at the source domain when they are required by a form or embedded widget; the visible site itself will be served locally.
- The current live site is the accepted visual design specification, so no redesign or generated concept is required.

## Audience And Goals
- Primary audience: event organizers, business leaders, readers, and potential advisory clients.
- Primary action: understand Franziska’s work and make contact or book her.
- Secondary actions: explore keynotes, books, journal posts, and biography content.

## Site Map
- `/` - homepage and overview.
- `/keynotes/` - speaking topics and booking information.
- `/books/` - books and purchase links.
- `/journal/` plus dated article routes - journal index and articles.
- `/about/` and public child pages - biography and related about content.
- `/contact/` - contact information and inquiry path.
- Additional public routes listed by the live WordPress sitemaps are included in the snapshot.

## Page Scaffolds
### Shared
- Desktop and mobile header with Franziska Iseli wordmark, navigation, dropdown, and social links.
- Existing page-specific hero, body sections, imagery, sliders, buttons, and embeds.
- Existing booking/contact footer, navigation columns, social links, and copyright.

### `/`
- Hero: full-width portrait with “COMMUNICATION. COURAGE. CREATIVITY.”
- Featured-in logo rail.
- Welcome and personal introduction.
- “Work With Franziska” services.
- Biography snapshot, testimonials, happy-client logos, and booking footer.
- SEO title: Home - Franziska Iseli.

## Visual Direction
- Mood: bright, confident, editorial, approachable.
- Palette: true white, charcoal/black typography, muted sage accent, cool light-gray section bands.
- Type: geometric sans-serif with uppercase editorial headings and a handwritten accent face.
- Imagery: the existing photography, book covers, client logos, and article imagery.
- Motion: retain the current navigation, dropdown, sliders, reveals, and responsive transitions wherever they work without WordPress.

## Components
- Navigation: source header and mobile menu.
- Footer: source booking/contact footer.
- Repeated elements: buttons, article cards, testimonials, sliders, logo strips, forms, and media embeds.

## Assets And Content
- Provided: the current public website and its public media library.
- Need to create: a deterministic mirror script, Cloudflare configuration, redirects/headers, and project documentation.
- Placeholder-safe: none; the live site content is the source of truth.

## Implementation Plan
- Stack: static HTML/CSS/JS snapshot, generated by Node.js with no runtime framework dependency.
- Output: `dist/`, deployable directly to Cloudflare Pages.
- Data/content model: source pages and assets are mirrored from the public WordPress sitemaps and same-origin dependencies.
- Responsive strategy: preserve the source site’s existing Divi responsive CSS and page markup.

## Agent Split
- Lead: source audit, snapshot pipeline, Cloudflare packaging, visual verification, and final integration.
- Workers: none; the user did not request delegated or parallel agent work.

## Acceptance Checks
- Build: snapshot completes without unresolved local page or asset paths.
- Link audit: internal HTML routes and downloaded assets resolve locally.
- Desktop visual check: compare the original and clone at 1280 × 720 across representative sections.
- Mobile visual check: compare at 390 × 844.
- Accessibility/SEO basics: preserve semantic source markup, metadata, canonical information, alt text, and heading structure.

## Deployment Plan
- Platform: Cloudflare Pages.
- Build command: `npm run build`.
- Output directory: `dist`.
- Local preview: `npm run preview`.
- Final URL: supplied by Cloudflare when the user connects the repository or runs the deployment command.
